# Thesis Management Platform (ΣΥΔΕ)

Course-mandated web-based project for managing thesis assignments, evaluations, and grading.

## 🛠️ Technologies Used

- **Frontend:** _**HTML**, **CSS**, **JavaScript**_  
- **Backend:** _**PHP**, **JavaScript**_
- **Database:** _**MySQL**_
